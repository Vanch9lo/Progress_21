# 🎓 Школьная система баллов

Полнофункциональная веб-система для управления баллами в школе.

## Новые функции! 🎉

### 📚 Система предметов
- **Учителя** привязаны к конкретным предметам
- **Запросы на иммунитет** автоматически отправляются учителям соответствующего предмета
- Учителя видят только запросы по своему предмету

### 🎬 Звонки с медиа
- Ученики могут загружать **видео со звуком** или **аудио файлы**
- Ссылки на YouTube, Vimeo или прямые ссылки на MP3/MP4

### 🏫 Классы
- Каждый ученик имеет класс (например: 9А, 10Б)
- Учителя видят классы учеников в списках

## Возможности

### 👨‍🎓 Ученики
- Просмотр баланса баллов и класса
- История получения баллов
- Запрос иммунитета от двойки по конкретному предмету (20 баллов)
- Запрос своего звонка с видео или аудио (10 баллов)
- Отслеживание статуса запросов

### 👨‍🏫 Учителя
- Привязка к конкретному предмету
- Начисление баллов ученикам за оценки
- **Просмотр запросов по своему предмету**
- Одобрение/отклонение запросов на иммунитет
- Система оценок:
  - Оценка 2: 0 баллов
  - Оценка 3: 0 баллов
  - Оценка 4: 5 баллов
  - Оценка 5: 10 баллов
- Защита от накрутки (максимум 5 наград в час одному ученику)

### 👑 Модераторы и Владелец
- Одобрение/отклонение всех запросов
- Просмотр всех пользователей с классами и предметами
- Начисление баллов любому пользователю
- Создание новых аккаунтов с указанием:
  - **Для учеников:** класс
  - **Для учителей:** предмет
- Удаление пользователей (только владелец)
- Просмотр статистики

## Как пользоваться

### 1. Создание учителей
1. Войдите как владелец (Ванчело)
2. Нажмите "Создать пользователя"
3. Выберите роль "Учитель"
4. Выберите предмет из списка
5. Создайте аккаунт

### 2. Создание учеников
1. Войдите как владелец или модератор
2. Нажмите "Создать пользователя"
3. Выберите роль "Ученик"
4. Укажите класс (например: 9А)
5. Создайте аккаунт

### 3. Начисление баллов (для учителей)
1. Войдите как учитель
2. Выберите ученика из списка
3. Выберите оценку (4 = 5 баллов, 5 = 10 баллов)
4. Нажмите "Начислить баллы"

### 4. Запрос иммунитета (для учеников)
1. Войдите как ученик
2. Нажмите "Иммунитет от 2"
3. Выберите предмет из списка
4. Подтвердите запрос (списывается 20 баллов)
5. Запрос автоматически отправится учителю этого предмета

### 5. Запрос звонка (для учеников)
1. Войдите как ученик
2. Нажмите "Свой звонок"
3. Выберите тип: видео или аудио
4. Вставьте ссылку на видео или аудио файл
5. Подтвердите запрос (списывается 10 баллов)

## API Endpoints

### Авторизация
- `POST /api/login` - Вход в систему
- `GET /api/me` - Информация о текущем пользователе
- `POST /api/register` - Регистрация (для модераторов/владельца)

### Ученики
- `GET /api/student/balance` - Баланс, класс и история
- `POST /api/student/immunity` - Запрос иммунитета (с предметом)
- `POST /api/student/bell` - Запрос звонка (с медиа)

### Учителя
- `POST /api/teacher/award` - Начислить баллы
- `GET /api/teacher/my-requests` - Запросы по предмету учителя
- `GET /api/students` - Список учеников

### Модераторы
- `GET /api/moderator/requests` - Ожидающие запросы
- `GET /api/moderator/requests/all` - Все запросы
- `POST /api/moderator/requests/:id` - Обработать запрос
- `GET /api/moderator/users` - Все пользователи
- `POST /api/moderator/add-points` - Начислить баллы
- `DELETE /api/moderator/users/:id` - Удалить пользователя (владелец)

### Статистика
- `GET /api/stats` - Общая статистика

## Безопасность

- Пароли хешируются с помощью bcrypt
- JWT токены для авторизации
- Ролевая модель доступа (RBAC)
- Защита от накрутки баллов

## Технологии

- **Backend:** Node.js, Express
- **Database:** SQLite (sql.js - чистый JavaScript, не требует компиляции!)
- **Auth:** JWT, bcrypt
- **Frontend:** HTML, CSS, JavaScript
